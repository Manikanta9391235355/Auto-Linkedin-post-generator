# 💼 LinkedIn AI Post Generator & Publisher

An AI-powered Streamlit application that generates LinkedIn posts based on a topic, optionally creates an AI-generated image, and publishes the post directly to LinkedIn.

This project automates the entire LinkedIn content creation workflow using Python, Streamlit, and LinkedIn APIs.

---

## 🚀 Features

- ✍️ AI-generated LinkedIn post content from a topic
- 🖼️ Optional AI image generation for posts
- 👀 Live preview of generated content
- 📤 One-click publishing to LinkedIn
- ⚡ Clean Streamlit UI (no warnings, no raw API responses)
- 🔁 Automatic fallback to text-only posts if image generation fails

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **LinkedIn REST API**
- **AI Text Generation**
- **AI Image Generation**
- **REST API Integration**
